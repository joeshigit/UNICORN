# 建表手冊

一張新表格從無到有的完整流程。

---

## 動手之前先想清楚三件事

1. **這張表要收什麼？** 每個欄位分別是什麼資料型態
2. **哪些欄位是選單？** 選單的值要跟現有的哪個 KEY 共用
3. **以後要怎麼找回這批資料？** 按學校找？按月份找？按分類找？

第 3 點決定了第 2 點。如果以後想「一次撈出所有粵華中學的資料」，
那學校欄位就一定要用 `school` 這個 KEY，不能自己另外開一個。

---

## Step 1 — 先把選項池準備好

進**選項池**。

### 表格分類與動作

`module`（分類）和 `action`（動作）第一次進系統會自動建好，裡面各有一個預設值。
先想好這張表屬於哪一類，不夠就加：

- `module`：`CAMP`、`ADMIN`、`HR`…
- `action`：`REGISTER`、`REPORT`、`APPLY`…

兩者合起來是這張表的識別，例如 `CAMP` + `REGISTER`。

### 下拉欄位的 KEY

看看要用的 KEY 在不在了。不在就「新增 KEY」：

| 欄位 | 說明 |
|------|------|
| KEY | 英文小寫開頭，跨所有表格統一，例如 `school`、`costCenter` |
| 清單名稱 | 給自己看的，例如「所有學校」 |

建好之後進去加選項。選項多的話用**批次貼上**，一行一個：

```
粵華中學
培正中學,培正
聖若瑟
```

有逗號就是「值,顯示名稱」，沒有就兩者相同。

> **值（value）建立後不要改。** 它是存進資料池的標準碼，改了歷史資料就對不上。
> 要換稱呼改「顯示名稱」就好。不再使用的選項設成「停用」，不要刪掉。

### 需要限縮選項時建子集

例如 `school` 有 100 間，但某張表只給 20 間教會小學選。
在該 KEY 上點「建立子集」，勾出那 20 間。

子集只能從 Master 挑，所以不管用哪一份清單填報，
存進資料池的都是同一套標準值，查詢完全不受影響。

---

## Step 2 — 建立表格

進**表格** →「建立表格」。

### 基本資訊

| 欄位 | 說明 |
|------|------|
| 表格名稱 | 清楚說明用途，例如「營會登記表」 |
| 分類 module | 從選項池挑 |
| 動作 action | 從選項池挑 |
| 說明 | 填報時會看到 |
| 啟用 | 打勾才會出現在填報中心 |

### 欄位

每個欄位挑一個 KEY，然後取顯示名稱。

- **固定 KEY**：文字（`title`、`text1/2`、`note`、`note2`）、數字（`quantity1~3`、`amount1/2`）、日期（`dateOnlyStart/End`、`dateTimeStart/End`）、檔案（`upload`、`upload2`）
- **選項池 KEY**：選了就是下拉欄位，還要再指定用哪一份清單（Master 或子集），可以勾「可複選」

型別由 KEY 決定，不用自己選。同一個 KEY 在同一張表只能用一次。

> 顯示名稱可以隨你高興。KEY 是 `school`，這張表叫它「入營學校」，
> 另一張表叫它「駐守學校」，都沒問題，資料照樣併得起來。

---

## Step 3 — 驗證

1. 到**填報**找到剛建好的表，實際填一筆
2. 到**資料池**確認欄位名稱、選項、順序都對
3. 匯出一次 CSV，確認欄位標題是「顯示名稱 (KEY)」的格式

---

## 之後要改表格

直接編輯就好。改了欄位，`version` 會 +1。

已經提交的資料帶著送出當下的版本號和名稱快照，
所以舊資料在資料池裡仍然顯示成當初的樣子，不會因為你改了表格就亂掉。

已經有資料的表格不能刪除，只能停用。

---

## 常見錯誤

| 錯誤 | 為什麼不行 |
|------|-----------|
| 每張表各自建自己的學校選項池 | 值會長出變體（粵華／粵華中學／粵華學校），跨表查詢就廢了 |
| 改掉選項的值 | 歷史資料存的是舊值，改了就對不上 |
| 用「顯示名稱」思考資料 | 顯示名稱只是外觀，查詢永遠是靠 KEY |
| 把不要的選項刪掉 | 設成「停用」就好，刪掉會讓舊資料失去對照 |
| 有資料的表格硬要刪 | 改用停用；表格是歷史資料的說明書 |
